# Agent Handoff

One-click local-to-cloud handoff for coding agents.

Tell your agent, “Move to the cloud and continue working.” Agent Handoff transfers the session, project changes, and development setup to a remote machine so work can continue with minimal interruption.

- Zed integration for Codex, Claude Code, and OpenCode.
- Uncommitted code transfer that preserves the local workspace.
- Dependency detection and remote environment setup.
- Your own machines over SSH, with managed sandboxes as another option.
- Session restoration where supported, with a continuation brief as a fallback.

A lightweight CLI and agent-specific adapters handle the transfer, recovery, and connection to the remote workspace.
