How it works

One sentence to your agent.
The rest happens on its own.

  1. 01

    Prepare

    Your agent notices you're leaving and warms a sandbox while you wrap up.

    handoff_prepare  →  sandbox warm
  2. 02

    Snapshot

    Every change, even uncommitted, goes up as one commit. Your working tree stays exactly as it was.

    temporary git index  →  handoff/h3k9
  3. 03

    Continue

    The same agent, or a different one, picks up from a written brief and opens a draft pull request.

    codex resumes  →  draft PR #12

Questions

What gets moved?
Committed, staged, unstaged, and new files as one snapshot commit, plus the brief. OpenCode sessions move in full.
Does my local workspace change?
No. The snapshot uses a temporary Git index. Your files, index, and branch stay as they are.
What do I need?
Node.js 22, a GitHub token that can push, a model key for the remote agent, and a provider account or an SSH machine.
What if my laptop is already closed?
That's the point. The helper finishes the transfer in the background, and the sandbox keeps going without you.
Can I watch or steer the remote agent?
Yes, on providers with SSH. Ask your agent for the handoff status to get the SSH command.
Is it free?
agent-handoff is open source. You pay your sandbox provider and model provider, or use your own machine.
